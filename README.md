# Instructions
Create python virtual environment. Must use python 3.12.

```bash
python3.12 -m venv .venv
```

Install dependencies within venv.

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Make sure to download the NPFC-Test_Database_V2.csv provided to run the notebook.

Run all notebooks within venv
